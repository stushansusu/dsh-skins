皮肤中心与皮肤集合随 dsh-web 家族对齐到统一版本。从本版本起，四个卫星仓（皮肤中心、宠物、社区插件索引、预设中心）与本仓发布同一个 X.Y.Z，卫星先发、本仓后发；版本号从 0.3.25 跳到 0.4.2 是这次对齐的结果，不是功能上的跨越。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-skin-center` 与安装方式不变。

### 修复

- Whale Mom（鲸鱼娘）皮肤：插件管理页在该皮肤下获得可读的界面底色，官方插件列表的文字不再与背景糊在一起

### 其他改动

- CI：pull request 自动路由到对应评审人
- 仓库脚手架打印的说明文案与当前仓库结构一致
- 文本文件统一以 LF 检出，避免跨平台换行差异

The skin center and the skin collection align to the dsh-web family's unified version. From this release on, the four satellite repositories (skin center, pet, community plugin index, preset center) publish the same X.Y.Z as this repository, satellites first and this repository after; the jump from 0.3.25 to 0.4.2 is that alignment, not a functional leap.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field, or profile format is renamed. The package name `@linxin666/dsh-client-ui-skin-center` and the install path are unchanged.

### Bug Fixes

- Whale Mom skin: the plugin manager page gets a readable surface under this skin, so the official plugin list text no longer blends into the background

### Other Changes

- CI: pull requests are routed to their reviewers automatically
- The description the repository scaffold prints now matches the repository layout
- Text files check out with LF line endings, so line endings no longer differ across platforms
