皮肤中心发布 0.4.10，沿用 dsh-web 家族的统一版本号。这是一次纯版本对齐：本仓没有任何功能改动，没有皮肤进出目录，SDK 队列与语义属性契约都不动。与 0.4.9 的唯一差异是版本字符串本身——`package.json` 的 `version`，以及构建期由 `__DSH_PKG_VERSION__` 常量烘进 `lib/client.js` 的那一行（`git diff --stat -- lib` 读作 1 insertion / 1 deletion）。除这一行外，两个版本的产物逐字节相同。

> **兼容性**：本版本没有破坏性变更，没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。以下标识是冻结的：包名 `@linxin666/dsh-client-ui-skin-center`；安装方式（`dsh plugin --profile <name> add` 与 `$DSH_HOME/skins/<id>` 目录布局）；npm `files` 白名单仍只内置 `blue-fantasy`；v2 活跃状态文档的持久化文件名与键名；`data-dsh-skin`、`data-dsh-part` 等语义属性名；线协议字段。`dsh.engines.dsh` 下限保持 `>=0.2.1-rc.3` 未动，与 0.4.9 一致，所以能装 0.4.9 的宿主同样能装 0.4.10，反之亦然。

### 其他改动

- 版本推进到 0.4.10，与 dsh-web 家族的统一版本线一致。本仓只发一个包，`package.json` 的 `version` 是唯一的版本声明；构建产物里唯一的变化是被编译期常量 `__DSH_PKG_VERSION__` 烘进去的版本串，`lib/client.js` 那一行从 `return "0.4.9";` 变为 `return "0.4.10";`，`lib/client.js.map` 与 `lib/index.js` 均未变动。皮肤自身的 manifest 版本不随家族版本走，本轮没有皮肤升版，皮肤目录仍是 62 套
