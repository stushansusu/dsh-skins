# 桂影月华 · Osmanthus Moonlight

[English](README.md) | 中文

暗色专用的 dsh web 皮肤：一整幅月夜桂花铺满外壳，界面全部退成夜色玻璃给画让路。
明暗两个主题走的是同一套，所以两个预览位放的是这套皮的**两个状态**，不是两个主题 ——
见[预览](#预览)。

## 构成

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（全部 `--dsw-alias-*` 语义
  token）+ `patches.css`（L3 自由选择器）+ 四支生成的 SVG 与两张位图底。没有
  package.json，没有构建步骤，没有 hooks。
- **暗色专用是构造出来的**：色板同时写在 `:root` 与 `body[data-ds-dark-theme]`
  上，所以系统无论要浅色还是要深色，看到的都是同一套夜；再用
  `html { color-scheme: dark !important }` 把原生控件也钉在暗色。
- **不加第二个月亮**：底图自己带着，皮肤只补家具。

## 画法

- **底图** —— 那张月夜图，明暗两个主题都走它；三段 scrim 把压暗的额度花在右侧
  亮部和下缘，暗的地方整片让出来。
- **侧栏** —— 右缘「靛在外、金在内」双线，再补一道极淡的金晕。
- **首屏** —— 两层月华柔光（一层借底图的月亮，一层暖金）。
- **顶栏** —— 左上角一整幅插画：月上桂梢、云头、三盏孔明灯、回纹边。
- **输入卡** —— 夜色玻璃 + 一圈金桂键线。
- **会话头部** —— 夜色玻璃 + 底缘一道 1px 金线。
- **工作区分组行** —— 做成灯谜签。
- **朱批** —— 中秋不兴朱砂，用「金桂在外、青玉在内」的一圈。

## 素材与署名

本套皮肤里的画，全部是作者自己的，或由作者的构建脚本从自己的画里生成：

- `assets/zq-bg.webp` —— 作者自己的月夜插画（明暗共用同一张）。
- `assets/zq-masthead.webp` —— 由作者自己的源图裁切生成。
- `assets/zq-folder-mooncake.png` —— 工作区文件夹图标，由作者的画生成。
- `assets/zq-row-tag.svg` 以及侧栏 / 头部 / 输入卡那几道描金 —— 仓库内的
  生成器画出来的。

没有打包任何第三方素材，画作经作者许可在本仓库分发。

## 安装

把本目录复制到 `$DSH_HOME/skins/mid-autumn/`，然后在皮肤中心里选中它。
