# 像素鲸海

[English](README.md) | 中文

俯视的像素海面，一头鲸鱼娘仰泳着来回游，侧边栏在下雨。

海不是一张画：十二阶水色、断续的破峰亮线、随浪走的碎浪点，全部按 256×144 逐像素算好再
最近邻放大，屏幕上每一格都是硬的。鲸鱼娘是立绘压出来的像素形象 —— 四十像素长、十色、
一圈深色描边，横躺水面，身体跟着划水一波波起伏。

## 这是什么

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（`--dsw-alias-*` token 全量重映射）+
  `patches.css`（L3 选择器）+ 生成的 GIF/SVG。无 package.json、无构建步骤、无 hooks。
- **暗色皮肤**：浅色与暗色两套主题下呈现同一片夜海；`skin.css` 把 96 个官方别名 token
  一起钉成深海配色，所以两个模式不会有色差。

## 画面

| 层 | 文件 | 说明 |
| --- | --- | --- |
| 海面 | `assets/sea.gif` | 256×144，500 帧，16.7fps，30 秒整循环 |
| 设置页 | `assets/sea-plain.gif` | 同一片海的无人物版本，192×108 |
| 雨幕 | `assets/rain-a.gif`、`rain-b.gif` | 160×220 透明 GIF，各自 4 秒循环，错位叠铺 |
| 工作区件 | `assets/*.svg` | 抖动颗粒、水线、像素鲸标、四角括号、气泡 |

**无缝**是算出来的，不是凑的：海面的浪相位、鲸鱼娘的游路、摆尾节拍全部是 500 帧的整数倍，
第 500 帧的下一帧就是第 1 帧。雨滴同理 —— 每滴在 4 秒里正好落整数次，落点开花也是周期内的。

## 配色

| 用途 | 值 |
| --- | --- |
| 最深的海 | `#050C15` |
| 浪尖 | `#55A3AC` |
| 碎浪 / 高光 | `#86CDC9` |
| 鲸鱼娘主色 | `#245AB4` |
| 描边 | `#0A1522` |
| 界面强调 | `#3FB3A9` |

海水 12 阶、角色 12 阶，加上 4 级暗角，一共 96 个调色板项 —— GIF 只有 256 色上限，够用。

## 工作区

侧边栏铺 8 像素抖动颗粒、底边一条阶梯水线、右下角一枚 20×10 像素鲸标，全在元素自身的
`background-image` 上（永远在内容后面）。输入卡直角、1 像素青边、3 像素硬投影、四角括号；
滚动条 6 像素直角细轨；所有 SVG 关掉抗锯齿并把线头改成方头。
