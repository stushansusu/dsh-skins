# 鲸鱼娘 · 清透水彩 (Whale Girl · Clear Watercolour)

[English](README.md) | 中文

**浅色专用**皮肤，画在一张水彩插画上：蓝发少女、发间缀满白色小花与白玫瑰与银色菱形
吊坠珠链、翡翠绿的眼、水彩质感的蓝天白云与散落花瓣。机壳不是画在画上，而是
**一层半透明的奶白薄纱 —— 画从纸背透出来**。色板里每一支都是从那张画里量出来的，
没有一支是凭眼睛挑的。

## 配色是量出来的，不是配出来的

这张画本身极亮（亮度中位 198）、饱和度极低（中位 0.10）——「低饱和水彩」是关于数据的
陈述，不是加上去的风格。全图没有滤镜、没有重新调色。

| 角色 | 色值 | 出处 |
| --- | --- | --- |
| 奶白（面板 / 纱的基色） | `#FAF9F5` | 画面里占 **34.6%** 的那片 |
| 墨蓝（正文） | `#0D2045` | 画面最暗 0.2% 的均值（`#0E2249`）再压深一档 |
| 蔚蓝（品牌 / 交互边界） | `#1B5D9A` | 画面最饱和 2% 的均值（`#1E66A9`）再压深一档 |
| 冰蓝（只做装饰线） | `#B0C8D8` | 云层那一档 |
| 翡翠（只给状态） | `#186654` | 眼睛实测绿 `#6F9C8F`（被水彩洗淡）同色相压深 |
| 雾蓝（悬停面） | `#E7EEF4` | 奶白与冰蓝之间 |

正文压在面板上：manifest 两个模式都是 **15.22:1**。

## 设计语言：一张水彩纸

| 元素 | 做法 |
| --- | --- |
| 面 | 半透明奶白薄纱 + `backdrop-filter`；纸边是 `0 1px 0` 的亮线，不是 `border` |
| 线 | **收笔**：所有横线都是两端淡出的 `linear-gradient`，不是通线 |
| 状态 | 翡翠只给：聚焦环、当前行左缘 2px 竖条、`[aria-selected]`、链接悬停 |
| 实心 | 机关上只有一处：发送键（新会话是纱底压一圈蔚蓝细线；发送键不可用时也退成线圈） |
| 字 | 标题走思源宋体，正文走思源黑 / 等线 |
| 柔光 | 卡内小字与正文各补一层**单向**白色 `text-shadow` —— 纸被字压厚了的观感 |
| 圆角 | 5 档：4 / 8 / 12 / 18 / 24 px，外加 999px 药丸 |

有一件事不能合成一支色：**装饰线走冰蓝，交互边界走蔚蓝 / 翡翠。** 冰蓝 `#B0C8D8`
压在这些纱的任何一层上都只有 1.65~2.18:1，永远到不了交互边界要的 3:1。

## 五个纱旋钮

| 令牌 | 值 | 画面保留 | 用在哪 |
| --- | --- | --- | --- |
| `--bk-veil-sidebar` | 0.56 | 44% | 侧栏 / 顶栏面板 / 工作区列表 |
| `--bk-veil-head` | 0.56 | 44% | 会话头部 |
| `--bk-veil-card` | 0.52 | 48% | 输入卡 / 新会话（带 `blur(12px)`） |
| `--bk-veil-sheet` | 0.38 | 62% | 会话正文纸（模糊挂在它的 `::before` 上） |
| `--bk-veil-menu` | 0.80 | 20% | 浮层 |

每一档都是**对着真实像素反解**出来的，而**取样方法很关键**：拿「盒子最暗 1%」当纸底，
量到的其实是**文字自己**（或她那一大片头发），于是每个面都被判厚一档。上表这组改成了
**按格取纸底** —— 14x48 的格、每格取 p75 亮度的真实像素当纸，再反解
`under = (P - a*VEIL)/(1-a)`，任意候选 α 都能重合成、逐样本复核。最差 5% 的文字格：
侧栏正文 **9.14:1**、会话头部 **8.18:1**、正文纸 **7.8:1**、输入卡 **10.67:1**，
次级与状态档全部 ≥5.2:1。**这一轮没有动任何文字色。**

会话正文纸是全皮最薄的一档（故意的）：62% 的画面直接透出来，她那一大片深蓝头发就在字底下；
再降到 0.34，正文就会跌到 7:1 的边缘。

（绝对下限的算法：把真壳每个盒子折回源图，量它底下最暗 1% 的亮度，再解
「要让次级文字过 4.5:1，纱最低要多少 alpha」。合成空间是 **sRGB（伽马编码）**，不是
线性光 —— 实测 `rgba(250,249,245,0.678)` 盖在 `rgb(38,60,100)` 上得到
`rgb(182,188,198)`，sRGB 预测逐通道命中（181.7 / 188.2 / 198.3），线性光预测差 29。
按线性光解会把每个面整体高估一档。模糊不能替代纱：会话纸底下是她一大片深蓝头发，
σ 从 0 加到 26 只把最薄比值从 0.79 抬到 0.96 —— 模糊抹得开细发丝，抹不掉大面积暗部。

## 浅色专用：色板同值，像素层靠钉

`light` 与 `dark` 写成**逐字节相同的值**（不写 `darkOnly`）：这是白昼的水彩，翻成
夜版就成了另一张画。

但色板同值并不等于像素同值。壳里还有四处会在 `body[data-ds-dark-theme]` 下另出一套值：

| 源 | 有多少 | 怎么钉 |
| --- | --- | --- |
| 引擎给 `--sk-*` 生成的暗色分支 | 5 支 | 在 `body:not(:root)` 上用与浅色侧同一个表达式重声明 |
| 本皮没重映射的外壳 token（不在官方 299 契约里，或在契约里但不在本皮 95 支重映射内） | 22 支 | 原样抄它在浅色下的取值 |
| 两条不是 token 的暗色规则（工具图标砖的底、右栏导引图形的色） | 2 条 | 按语义钩子 + 结构，在分片里单独钉 |
| `color-scheme: dark`（会让所有没有作者色的原生控件变白字） | 1 条 | `body:not(:root)[data-ds-dark-theme] { color-scheme: light }` |

本皮是**浅色专用**，所以商店的暗色档位会显示两张**逐字节相同**的预览图（`preview/light.jpg`
与 `preview/dark.jpg` 的 sha256 相同，`32758B56…3429C4`），暗色用户切过来得到的也是同一套
浅色界面 —— 这是刻意为之，不是漏了暗色素材。

## 验收

上面每一个数都是在跑着的真壳（:19387）与官方市场试穿页上量出来的，不是估的：

| 量什么 | 结果 |
| --- | --- |
| 外壳在 `body` 上声明的全部自定义属性，浅 vs 暗 | **0 / 553 不同** |
| 全部可见元素的 computed 样式，浅 vs 暗，真壳上 8 个场景（首屏 / 会话 / 右栏 / 设置 / 菜单 / 输入卡聚焦 / 输入卡菜单 / 悬停卡） | **0 处差异**（仅剩的残差是两次快照之间「正在流式输出的新行」与一条被截在动画中途的入场） |
| 浅色侧：钉之前 vs 钉之后 | **36 / 36 支取值未变** |
| 官方试穿页渲染，浅 vs 暗，1680x1000 | **1,680,000 个像素里 0 个不同** |
| 对照组：同一台量具跑一张双主题皮 | 99.999% 的像素不同（证明量具真的在切主题） |
