# Windows XP · 蓝天绿丘（Win XP · Bliss）

[English](README.md) | 中文

一套**双主题**的 dsh 皮肤，把机壳拆成一台 Windows XP：侧栏是一台 XP 窗口（Luna 标题栏压着
任务窗格），中栏是桌面上的第二台，输入卡是一台带凹陷编辑框与工具条的小窗口，视口最底那
24px 画成任务栏。

两套主题**不是**一套色的明暗孪生，而是 XP 的两个真实视觉样式，各自锚定在作者自己拍的一张
照片上：

| | 浅色 · Luna Blue | 暗色 · Royale Noir |
| --- | --- | --- |
| 壁纸 | 白天：蓝天下的绿丘 | 夜里：同一构图的夜景 |
| 窗口面 | `#ECE9D8` | `#2B2B2B` |
| 客户区 | `#FFFFFF` | `#1C1C1C` |
| 标题栏 | Luna 蓝渐变 | 石墨蓝渐变 |
| 选中蓝 | `#316AC5` | `#2A5C9E` |
| 正文 | `#000000` | `#E8E8E8` |

两组之间**没有共用常量**。

## 它是什么

- **纯素材**：`skin.json`（v2 清单）+ `skin.css`（`--dsw-alias-*` 全量 token 重映射）
  + `patches.css`（L3 自由选择器）+ 19 枚手写 SVG 与两张壁纸。没有 package.json、
  没有构建步骤、**没有 hooks** —— 这套皮里没有一行会执行的代码。
- **照片背景**（`backgroundMedia.type = "image"`，每个主题一张 WebP），`scrim` 只压
  画面的两头，中间那座山整片让出来。
- **两套主题都是正经的**：浅色与暗色各有自己的色板、壁纸与机壳渐变。
- 地面全透（`glassBase: 0`）：**壁纸就是桌面**，面板是压在上面的不透明 XP 窗口。

## 还原了哪些 XP 的东西

| XP 的元素 | 落在哪 | 怎么做 |
| --- | --- | --- |
| Luna 标题栏 | 侧栏顶上 62px | 八段竖向渐变：上缘高光 → 主体 → 底缘第二道高光 → 深色收边 |
| 四色旗窗口图标 | 品牌行左侧 | 内联 SVG 当 background-image |
| 标题栏按钮 | 壳自带的「收起侧边栏」 | 半透明白高光 + 1px 描边 |
| 任务窗格 | 侧栏下半 | 米灰横带压着一个白色列表框（1px 灰蓝内凹描边） |
| 黄文件夹 / 白文档 | 工作区分组行 / 会话行 | 全彩 SVG 当 background-image；壳自己的字形用 `visibility` 隐掉（不用 `display`），16px 的位子不挪 |
| XP 选中蓝 | 会话行选中态 | `#316AC5` 底 + 白字 + 1px 深蓝内边 |
| 菜单 / 工具带 | 会话头部 76px | 40px Luna 标题栏 + 36px 工具带，1px 分隔线烘进渐变 |
| XP 页签 | 对话 / 轨迹 / 工具统计 | 直角；未选纯文字，选中白面 + 2px 品牌底线 |
| 凹陷编辑框 | 整张输入卡 | 客户区底色 + 与壳自带输入框同一支 `#7F9DB9` 描边 —— 全 App 的输入框因此同色同边 |
| 工具条抓手 | 输入卡工具条左端 | 5x9 的两列小点，画在那一行的左内边距里 |
| 蓝色默认按钮 | 发送键 | Luna 蓝渐变 + 深蓝描边 + 上缘白高光；禁用态退回米灰 |
| 琥珀热点 | 所有工具条按钮 | XP 的按钮热点是黄的，不是蓝的 |
| 淡黄提示条 | `role="tooltip"` | `#FFFFE1` 底 + 1px 黑边 + 直角（两个主题都保留） |
| 16px 滚动条 | 全局 | 凸起滑块 + 两端各一枚箭头键 |
| 任务窗格标题带 | 右栏顶上 38px | 与侧栏「工作区」同款的白高光 → face 横带 |
| 任务栏 | 视口最底 24px | frame 用 `padding-bottom` 让位；条子本身是 `::after` 上叠的 13 层背景：开始键、四色旗、任务按钮、托盘凹槽与两颗托盘小图标 |
| 窗口边框 | 拖列时的分隔条 | 悬停亮起一条 3px Luna 蓝（XP 里拖窗口就是抓边框） |

三个氛围层（`pane` / `sidebar` / `hero`）**全是 `none`**：画面就是那张照片，唯一的
压暗来自声明的 `scrim`。

## 真壳实测（1296x828，桌面端条件）

| 项 | 值 |
| --- | --- |
| 侧栏 | `0,0,280,804`（视口 − 24px 任务栏），标题栏 62px |
| 会话头部 | `0..40` Luna 渐变，`40..76` 工具带（底缘 1px 分隔线） |
| 输入卡 | 空会话 `928x116` / 会话里 `928x100`；平底色 + `#7F9DB9` 描边 + 内凹 |
| 任务栏 | 开始键 `0..72`（绿键 `0..71`，`71..72` 一条深绿分隔线，四色旗 `13..30`，两个字 `32..56`）、任务按钮 `104..252`、通知区 `right 96px` 起 |
| 输入卡工具条 | 行 `710x42`，内边距 `2px 8px 6px` → 左 16px（抓手钉在 5px，「+」按钮留 5px 气口） |
| 右栏顶带 | tablist `714,0,582,38`；`#F6F5ED` 渐到 `#ECE9D8`，37.7px 处一条 `#ACA899` |
| 设置面板 | `802x782`，左栏 `nav` 188 宽 |

文字对比度（取文字矩形**外面一圈**的实际落屏像素算 WCAG）：

| | 段数 | < 4.5:1 | < 3.0:1 | 最紧 |
| --- | --- | --- | --- | --- |
| 空会话 · 浅 / 暗 | 36 / 36 | 1 / 1 | 0 / 0 | 3.95 / 3.97 |
| 会话里 · 浅 / 暗 | 70 / 70 | 1 / 1 | 0 / 0 | 3.95 / 3.97 |
| 设置 · 浅 / 暗 | 39 / 39 | 1 / 1 | 0 / 1 | 3.29 / 2.92 |

唯一低于 4.5:1 的是**输入框占位符**，而且是刻意的：XP 的占位符就是淡灰 `#808080`，
再压深就不像 XP 了。设置面板那一条来自插件自己写死的橙色，不是这套皮的问题。

## 可读性说明

- 浅色正文是纯黑压在 `#FFFFFF` 上，暗色是 `#E8E8E8` 压在 `#1C1C1C` 上；除上面那条
  占位符之外，量到的每一段都在 4.5:1 以上。
- 悬停只换背景渐变，不做位移；焦点框用的是 XP 的点线矩形，而不是把焦点指示去掉。
- 任务栏是 `pointer-events: none` —— 绝不吃点击，而且 frame 替它留了高度，不会压到
  任何控件。

## 已知限制

- 任务栏上那两处文字（开始键的「开始」、任务按钮的标题）是**固定尺寸的 SVG**。
  CSS 画不出文字，所以界面切英文时它们仍是中文字，任务按钮上写的也始终是应用名、
  而不是当前会话名。要它们活起来得用 hooks，而本皮肤刻意不声明 hooks。
- **不画窗口三键**：会话头部只有一两颗壳的真实按钮，做「最小化/最大化/关闭」三连会
  误导（形状改了但功能不是那个）。

## 安装

把这个目录放到 `$DSH_HOME/skins/windows-xp`，或在皮肤中心里安装。两套主题都声明了，
系统主题切换不需要刷新。
