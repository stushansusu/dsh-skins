# Windows XP · 蓝天绿丘（Win XP · Bliss）

[English](README.md) | 中文

一套**双主题**的 dsh 皮肤，把机壳拆成一台 Windows XP：最顶上那 40px 就是应用自己的窗口条
（左边是「应用 / 编辑」，右边是系统的最小化 / 还原 / 关闭），侧栏是一台 XP 窗口、顶上那行是
任务窗格标题带，中栏顶上是一整条 76px 工具带，输入卡是一台带凹陷编辑框与工具条的小窗口，
视口最底那 24px 画成任务栏。

两套主题**不是**一套色的明暗孪生，而是 XP 的两个真实视觉样式，各自锚定在作者自己拍的一张
照片上：

| | 浅色 · Luna Blue | 暗色 · Royale Noir |
| --- | --- | --- |
| 壁纸 | 白天：蓝天下的绿丘 | 夜里：同一构图的夜景 |
| 窗口面 | `#ECE9D8` | `#2B2B2B` |
| 客户区 | `#FFFFFF` | `#1C1C1C` |
| 标题栏 | Luna 蓝渐变 | 石墨蓝渐变 |
| 选中蓝 | `#316AC5` | `#2A5C9E` |
| 正文 | `#000000` | `#E8E8E8` |

两组之间**没有共用常量**。

## 它是什么

- **纯素材**：`skin.json`（v2 清单）+ `skin.css`（`--dsw-alias-*` 全量 token 重映射）
  + `patches.css`（L3 自由选择器）+ 17 枚手写 SVG 与两张壁纸。没有 package.json、
  没有构建步骤、**没有 hooks** —— 这套皮里没有一行会执行的代码。
- **照片背景**（`backgroundMedia.type = "image"`，每个主题一张 WebP），`scrim` 只压
  画面的两头，中间那座山整片让出来。
- **两套主题都是正经的**：浅色与暗色各有自己的色板、壁纸与机壳渐变。
- 地面全透（`glassBase: 0`）：**壁纸就是桌面**，面板是压在上面的不透明 XP 窗口。

## 还原了哪些 XP 的东西

| XP 的元素 | 落在哪 | 怎么做 |
| --- | --- | --- |
| 窗口标题栏 | 视口最顶上那 40px（`[data-dsh-frame]::before`） | 八段 Luna 蓝渐变（暗色石墨蓝）+ 下缘深色发丝。这一条**就是**应用的窗口标题栏 —— 系统那三个窗口键就画在它右端 |
| 「应用 / 编辑」菜单 | `body > div[data-windows-menu]`（桌面端 preload 注入，在影子根里） | 影子根只让样式表碰到**继承下来的** token，所以皮肤在宿主那一层重下那几支：白字 + 半透明悬停 |
| 系统窗口三键 | Electron `titleBarOverlay`（CSS 碰不到） | preload 会量一个 probe span 的 `--dsw-specific-sidebar-fill` 与 `--dsw-alias-label-primary` 交给 `setTitleBarOverlay()`；皮肤把这两支 token 下到**那个 span 自己**身上 —— 底全透明 + 符号白，三个键就落在蓝条上 |
| 四色旗窗口图标 | 品牌行左侧 | 内联 SVG 当 background-image |
| 侧栏任务窗格标题带 | 侧栏顶上那行（`logoRow`） | 白高光渐到淡蓝，上缘一道白线、下缘一条品牌蓝发丝；「Win XP」深蓝粗体（浅色 9.5:1 / 暗色 6.9:1） |
| 收起侧边栏 | 壳自带的「收起侧边栏」 | 均匀的浅键 + 深蓝图标（暗色反相）。它有两种落点、样式表分不出来 —— 网页端在侧栏的任务窗格标题带上，桌面端在窗口标题栏左上角 —— 所以一颗键要在两种底上都读得清 |
| 任务窗格 | 侧栏下半 | 米灰横带压着一个白色列表框（1px 灰蓝内凹描边） |
| 黄文件夹 / 白文档 | 工作区分组行 / 会话行 | 全彩 SVG 当 background-image；壳自己的字形用 `visibility` 隐掉（不用 `display`），16px 的位子不挪 |
| XP 选中蓝 | 会话行选中态 | `#316AC5` 底 + 白字 + 1px 深蓝内边 |
| 菜单 / 工具带 | 会话头部 76px | 一整条米灰工具带（标题行 + 页签行），底缘 1px 分隔线烘进渐变 |
| XP 页签 | 对话 / 轨迹 / 工具统计 | 直角；未选纯文字，选中白面 + 2px 品牌底线 |
| 凹陷编辑框 | 整张输入卡 | 客户区底色 + 与壳自带输入框同一支 `#7F9DB9` 描边 —— 全 App 的输入框因此同色同边 |
| 工具条抓手 | 输入卡工具条左端 | 5x9 的两列小点，画在那一行的左内边距里 |
| 蓝色默认按钮 | 发送键 | Luna 蓝渐变 + 深蓝描边 + 上缘白高光；禁用态退回米灰 |
| 琥珀热点 | 所有工具条按钮 | XP 的按钮热点是黄的，不是蓝的 |
| 淡黄提示条 | `role="tooltip"` | `#FFFFE1` 底 + 1px 黑边 + 直角（两个主题都保留） |
| 16px 滚动条 | 全局 | 凸起滑块 + 两端各一枚箭头键 |
| 任务窗格标题带 | 右栏顶上 38px | 与侧栏「工作区」同款的白高光 → face 横带 |
| 任务栏 | 视口最底 24px | frame 用 `padding-bottom` 让位；条子本身是 `::after` 上叠的 14 层背景：开始键、任务按钮与托盘的十二层、以及条子底色。任务按钮里是「四色旗 → 窗口名 → 蓝键」，次序不能反 |
| 窗口边框 | 拖列时的分隔条 | 悬停亮起一条 3px Luna 蓝（XP 里拖窗口就是抓边框） |

三个氛围层（`pane` / `sidebar` / `hero`）**全是 `none`**：画面就是那张照片，唯一的
压暗来自声明的 `scrim`。

`--dsh-windows-titlebar-height: 40px`；只挂属性不设变量时 `padding-top: var(…)` 在计算值阶段
就是无效值，所有列都会量在 y=0、顶栏也没有高度）

| 项 | 值 |
| --- | --- |
| 窗口顶栏 | `0,0,1296,40`，Luna 渐变 + 下缘 `rgba(0,0,0,.3)` 发丝；preload 那个量色 span 解出 `rgba(0,0,0,0)` 底 + `rgb(255,255,255)` 符号 |
| 侧栏 | `0,40,280,764`（视口 − 40px 顶栏 − 24px 任务栏）；顶上 40px 是任务窗格标题带 |
| 会话头部 | `40..116` 一整条 76px 工具带（底缘 1px 分隔线）；上面那 40px 是窗口条 |
| 输入卡 | 空会话 `928x116` / 会话里 `928x100`；平底色 + `#7F9DB9` 描边 + 内凹 |
| 任务栏 | 开始键 `0..72`（绿键 `0..71`，`71..72` 一条深绿分隔线，四色旗 `13..30`，两个字 `32..56`）、任务按钮 `104..252`（旗 `116..133`、窗口名 `138..248`）、通知区 `right 96px` 起 |
| 输入卡工具条 | 行 `710x42`，内边距 `2px 8px 6px` → 左 16px（抓手钉在 5px，「+」按钮留 5px 气口） |
| 右栏顶带 | tablist `714,0,582,38`；`#F6F5ED` 渐到 `#ECE9D8`，37.7px 处一条 `#ACA899` |
| 设置面板 | `802x782`，左栏 `nav` 188 宽 |

文字对比度（取文字矩形**外面一圈**的实际落屏像素算 WCAG）：

| | 段数 | < 4.5:1 | < 3.0:1 | 最紧 |
| --- | --- | --- | --- | --- |
| 空会话 · 浅 / 暗 | 36 / 36 | 1 / 1 | 0 / 0 | 3.95 / 3.97 |
| 会话里 · 浅 / 暗 | 70 / 70 | 1 / 1 | 0 / 0 | 3.95 / 3.97 |
| 设置 · 浅 / 暗 | 39 / 39 | 1 / 1 | 0 / 1 | 3.29 / 2.92 |

唯一低于 4.5:1 的是**输入框占位符**，而且是刻意的：XP 的占位符就是淡灰 `#808080`，
再压深就不像 XP 了。设置面板那一条来自插件自己写死的橙色，不是这套皮的问题。

## 可读性说明

- 浅色正文是纯黑压在 `#FFFFFF` 上，暗色是 `#E8E8E8` 压在 `#1C1C1C` 上；除上面那条
  占位符之外，量到的每一段都在 4.5:1 以上。
- 悬停只换背景渐变，不做位移；焦点框用的是 XP 的点线矩形，而不是把焦点指示去掉。
- 任务栏是 `pointer-events: none` —— 绝不吃点击，而且 frame 替它留了高度，不会压到
  任何控件。

## 已知限制

- 皮肤自己画的两处文字（开始键的「开始」、任务按钮上的窗口名）是**固定尺寸的 SVG**。
  CSS 画不出文字，所以界面切英文时开始键仍是中文，任务按钮上写的也始终是应用名、
  而不是当前会话名。要它们活起来得用 hooks，而本皮肤刻意不声明 hooks。
- 顶栏那三个窗口键是 **Electron 自己的 `titleBarOverlay`，不是皮肤画的**：皮肤只能把
  覆盖层改成透明、符号改成白，让它们落在蓝条上。网页端没有这条顶栏（`content: none`、
  高度 0），那两个菜单与三个键也不存在。

## 安装

把这个目录放到 `$DSH_HOME/skins/windows-xp`，或在皮肤中心里安装。两套主题都声明了，
系统主题切换不需要刷新。
