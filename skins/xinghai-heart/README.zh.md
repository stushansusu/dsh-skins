# 星海之心 (Heart of the Starry Sea)

[English](README.md) | 中文

暗色专用皮肤，建在**一段背景视频**上：一片深蓝的星海从纯黑里一点一点点亮，11.5s 与
18.5s 各有一次星芒盛放。界面画成一张**星图** —— 画面本身是**点状**的（p99.5 以上的星点
中位尺寸只有 2px），所以机壳由**点与短虚线**构成，而不是姊妹皮那套连续的 1px 霓虹线。

全片 hue 有 76.9% 落在 210-240、R−B ≈ −46、暖色像素（R > B+10）**0.000%**。
冷色骨架在画面里没有任何对手，所以暖金被严格限制在**状态**上，
并因此引入了第三个角色：

> 骨架 = 星蓝（线，且多为点线） | 活口 = 暖金（只给状态） | **星点 = 亮星 #9ACAE6（节点 / 角点）**

## 设计语言：以点代线

这一套的第一版是从姊妹皮换色来的，被一眼指出「完全就是未至之境换了个颜色」。
装饰语言按画面本身的证据重做：

| | 未至之境 / 雨夜 | 这一套 |
| --- | --- | --- |
| 线的语汇 | 连续 1px 实线 | **点线 2px 实 + 4px 空** |
| 四角装饰 | L 形实线括号 | **四颗星点** |
| 状态标记 | 2px 实心竖条 | **2px 点轨** |
| 悬停反馈 | 斜向扫光 | **星芒光晕**（中空） |
| 圆角 | 8-12px 柔圆角 | **3px 图表式硬边** |
| 分区小标 | 暖金（与状态同色） | **亮星** —— 暖金从此只给状态 |
| 品牌行 | 2px 暖金竖棒 | **四芒星标** |
| 空会话 | 什么都不画（纯画面） | **也不画** —— 画面本身就是主角 |

空会话首屏**什么都不画**。早先一版在那里铺过一张极淡的星图（两圈同心环 + 12 颗星点 +
一颗 2.4px 的暖金「心」，共 16 层 radial-gradient），评审时撤掉了：这条片子的整个首屏
只有 **304 个暖色像素（0.018%）**，那颗饱和的金点再配上两圈同心环，读起来是一个
金色圆环装饰而不是星图。首屏让画面本身当主角，与姊妹皮一致。

## 柔和的阅读层

背景上挂了两层柔和的 scrim：竖向从 54% 起一条坡到 0.38（负责输入卡），
横向让左侧 16%（侧栏所在那条近黑的海沟）几乎不动、往右升到 0.24（负责对话列）。
逐字形对比度实测（中位，括弧里是最差 15%）：

| 元素 | 加层前 | 加层后 |
| --- | --- | --- |
| 输入卡占位符（会话） | 8.16:1（3.57） | **13.21:1（8.56）** |
| 输入卡占位符（首屏） | 9.85:1（4.85） | **11.98:1（5.92）** |
| 助手段落 | 16.29:1（10.73） | **16.68:1（12.27）** |
| 模型 pill | 9.67:1（7.38） | **10.63:1（9.54）** |

用的是渐变而不是模糊：backdrop-filter 会把壁纸毁掉（同一帧的屏幕像素与解码帧相关性
0.996 → 0.87）。代价也量了 —— 对话列现在透出约 59-77% 的画面。

## 视频为什么是 14.26 MB

商店把一个皮肤作为**单个 zip 资产**上架，而 Cloudflare Workers 对单个资产的上限是 **25 MiB**。
这条视频第一版是**零重编**的原文拷贝（21.01 MB，循环点硬切）；无缝版（CRF 15）是 29.47 MB，
**放不进去**。发行档改为：30fps 原生 / 1920 原生宽 / CRF 21 / tune film / 尾部淡出到黑 ——
**14.26 MB，与源片 SSIM 0.9932**，高于已接受的 rainy-night 那一版（0.9917）。

## 验证

上面每个数字都是在真壳里量出来的，不是估的：画面保真度回归（屏幕像素对解码帧）、
逐字形对比度、以及一次覆盖率扫描（把每个可见元素的 computed paint 拿去比对色板，
五个状态 0 BARE / 0 LIGHT）。官方关卡零 warning 通过。
