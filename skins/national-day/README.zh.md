# 国庆 · 山河华灯（National Day）

[English](README.md) | 中文

双主题 dsh 皮肤，两套配色来自两幅画：浅色走白昼的长城秋色，暗色走夜空的故宫烟花。
两组之间没有共用的常量 —— 这不是同一套值的明暗孪生，是两条独立的配色线。

## 这是什么

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整的 `--dsw-alias-*` token
  重映射）+ `patches.css`（L3 自由选择器）+ 目录内三件素材。无 package.json、
  无构建步骤、无 hooks。
- **界面先给画让路**：侧栏与详情栏从引擎写死的不透明实色墙换成同色系玻璃；
  Windows 桌面端外壳会往整块画框刷不透明底，这里把它置透明，用户给的画才露得出来。
- **工作区做成一面面渐隐的五星红旗横幅**（旗红左实右无 + 金星 + 名字居中），
  输入卡一圈品牌细边、下缘四颗药丸统一成胶囊。
- **会话视图另有一条阅读纱**，并按「纱之后的地面」重下了三支次要文字令牌 ——
  在此之前，过程行那 13px 小字在白昼那张画上只有 2.06:1。

## 两个主题是两幅画

| | 浅色 · 秋山晴日 | 暗色 · 故宫夜宴 |
| --- | --- | --- |
| 底图 | 蓝天白云、长城入雾、漫山红枫、红旗 | 夜空、故宫角楼、烟花、宫灯、银杏 |
| 品牌色 | 旗红 | 宫灯红 |
| 强调色 | 枫金 | 烟花金 |
| 正文 | 暖墨 | 暖白 |

## 界面做了什么

| 面 | 做法 |
| --- | --- |
| 分组标题「工作区」 | 灰字提成品牌色小标（600 字重 + 0.08em 字距） |
| 品牌行 | 「DSH 本地构建」→ **鲸鱼娘·人民万岁**（思源宋体 700） |
| 标题右侧三颗图标 | 静息无底，悬停品牌色底 + 品牌色图标 |
| 工作区分组行 | 一面**渐隐的五星红旗横幅**：旗红从左边实到右边无，金星在旗杆那头，名字居中 |
| 展开中的分组行 | 同一面旗压得更实 + 左侧 3px **金星色**竖条 |
| 会话行 | 静息是松一档的正文色；选中给品牌底 + 左竖条 + 500 字重 |
| 输入卡 | 1px 品牌细边 + 投影；聚焦时 1px 亮边 + 4px 柔环 |
| 下缘四颗药丸 | 工作区选择 / Agent 预设 / 模型 / 访问模式统一成胶囊，悬停品牌色 |
| 会话视图 | 阅读纱（首屏不加）+ 三支次要文字令牌重下 |
| 会话头部 | 一档主题玻璃 + 品牌色下缘 |
| 工作区搜索框展开态 | 纸底 + 品牌细边 |
| 外壳画框 | Windows 桌面端置透明，把画让出来（标题栏拖拽横带保留） |

选择器全部走 ARIA（`role=treeitem[aria-expanded]` / `[aria-selected]`）与官方
`data-slot`，没有一处哈希类名。

**分组行那个五角星**是换掉壳自带文件夹图标的：形状全在 svg 的 `d` 里，CSS 改不动，
只能「保留 svg 占位 + `visibility: hidden`，星形用 `mask-image` 画在 span 自己身上」。
不能 `display: none` —— span 的宽度是 svg 撑出来的，藏掉会让整列标题左移 16px。

**背景变成红之后，金色必须重新算。** 枫金 `#C8871F` 压在旗红上只有 1.6:1，等于消失；
金星是把它往白里提 45%，量到浅色 4.9:1 / 暗色 5.6:1。
